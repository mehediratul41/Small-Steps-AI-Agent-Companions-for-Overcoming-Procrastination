# Small Steps — AI Agent Companions for Overcoming Procrastination

Human–AI Interaction research on self-control and task initiation.

Small Steps is a bilingual (English/Japanese) research application investigating how Self-Agent and Friend-Agent support self-control, task initiation, and reduced procrastination.

Built with Flutter and FastAPI, with a standard notification control condition for comparison.

Research prototype developed for a master’s project at Shimane University, Japan. This repository does not establish intervention effectiveness.

## Research data and credentials

Keep participant records, consent forms, conversation exports, recordings, databases, API credentials, and local configuration outside this public repository. The `.gitignore` excludes common private-data paths and local artifacts; it cannot detect every sensitive file or remove anything already committed. Use synthetic fixtures for tests and review staged changes before publishing source code. Only placeholder configuration belongs in `.env.example`.
